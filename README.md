# ⚡ Blaster Kids

A toy blaster for kids: **particles, synthesized sounds, alphabet & numbers — no ads, no tracking, no Google, works offline.**

Single HTML file. No dependencies. No network requests.

## ✨ Features

- **29 modes**
  - **Powder:** Pistola, Rifle, Escopeta, Metralha, Sniper, Canhão, Silenciador, Mosquete
  - **Laser:** Laser, Plasma, Zap, Warp, Canhão Laser, Alien, Fóton, Quântico, Retrô
  - **Special:** Disco, Bolha, Robô, Arco
  - **Elements:** Raio, Trovão, Fogo, Gelo, Água
  - **Educational:** Alfabeto (A–Z, "A de Abacaxi"), Números (0–20, spoken in pt-BR)
  - **Random:** chaos mode
- **Canvas particle engine**: sparks, smoke, shell casings, lightning bolts, fireballs, ice shards, water drops, confetti, floating letters, shockwave rings
- **All audio synthesized with Web Audio** — no sound files, no downloads
- **Speech synthesis** (pt-BR) for the alphabet/numbers modes
- **Combo counter**, screen shake, haptics, text popups
- Kid-friendly neon UI, fullscreen, touch-first

## ▶️ Run

Just open `index.html` in any modern browser (Android, iOS, desktop).

Or serve it:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## 🔒 Privacy

No analytics, no ads, no external requests, no accounts. Everything runs locally in the browser.
